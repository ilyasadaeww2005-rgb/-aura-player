# AURA Player

AURA — устанавливаемый музыкальный PWA-плеер для iPhone. Он работает через GitHub Pages, импортирует аудиофайлы из приложения «Файлы» и сохраняет их локально в IndexedDB. Музыка не загружается на сервер.

## Возможности

- импорт MP3, M4A, AAC, WAV, OGG и FLAC (поддержка формата зависит от Safari);
- локальная медиатека с поиском, сортировкой и любимыми треками;
- очередь, shuffle, repeat one/all, таймер сна;
- чтение названия, исполнителя, альбома и обложки из ID3-тегов MP3;
- системное управление через экран блокировки iOS (Media Session);
- офлайн-интерфейс и установка на экран «Домой»;
- четыре цветовых акцента;
- отсутствие аналитики, аккаунтов и загрузки файлов в облако.

## Публикация на GitHub Pages

Публикация запускается автоматически после загрузки файлов в ветку `main`. Через 1–2 минуты приложение будет доступно по адресу `https://USERNAME.github.io/REPOSITORY/`. Статус можно посмотреть во вкладке **Actions**.

## Установка на iPhone

Откройте ссылку в Safari, нажмите **Поделиться** → **На экран «Домой»** → **Добавить**.

> iOS может очищать данные редко используемых сайтов при нехватке места. Храните оригиналы треков в приложении «Файлы».
